# Deployment Guide - Vanguardia Financial

This guide explains how to deploy your Next.js frontend and FastAPI backend to production.

---

## **Recommended Setup: Vercel + Railway**

### **Why This Stack?**
- ✅ **Simple**: Both platforms auto-detect and deploy
- ✅ **Affordable**: Vercel free, Railway $5/month
- ✅ **Fast**: Excellent global performance
- ✅ **PostgreSQL included**: Railway has built-in database
- ✅ **Auto-deploy**: Push to GitHub → auto-deploys
- ✅ **SSL included**: Free HTTPS on both platforms

## **Part 1: Deploy Backend (FastAPI) to Railway**

### **Step 1: Create Railway Account**
1. Go to https://railway.app
2. Sign up with GitHub
3. Click "New Project"

### **Step 2: Deploy Backend**

**Option A: Deploy from GitHub (Recommended)**
1. Click "Deploy from GitHub repo"
2. Select `Vanguard-Trading` repository
3. Choose `backend` folder as root directory
4. Railway auto-detects Python and deploys

**Option B: Deploy from CLI**
```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Navigate to backend folder
cd backend

# Initialize and deploy
railway init
railway up
```

### **Step 3: Add PostgreSQL Database**
1. In Railway dashboard, click "+ New"
2. Select "Database" → "PostgreSQL"
3. Railway automatically creates `DATABASE_URL` environment variable
4. Your backend will connect automatically

### **Step 4: Add Environment Variables**

In Railway dashboard, add these variables:

```env
# Database (auto-generated by Railway)
DATABASE_URL=postgresql://...

# Security
SECRET_KEY=your-secret-key-here-change-this
JWT_SECRET_KEY=your-jwt-secret-change-this

# CORS (add your Vercel domain after frontend deployment)
CORS_ORIGINS=https://your-app.vercel.app,https://vanguardiafinancial.com

# CoinGecko API (optional)
COINGECKO_API_KEY=your-api-key-if-you-have-one

# Redis (if needed)
REDIS_URL=redis://...
```

### **Step 5: Get Backend URL**

After deployment, Railway gives you a URL like:
```
https://vanguardia-backend-production.up.railway.app
```

**Save this URL** - you'll need it for frontend deployment.

### **Step 6: Test Backend**

Visit: `https://your-backend-url.railway.app/api/health`

You should see:
```json
{"status": "healthy"}
```

## **Part 2: Deploy Frontend (Next.js) to Vercel**

### **Step 1: Create Vercel Account**
1. Go to https://vercel.com
2. Sign up with GitHub
3. Click "Add New" → "Project"

### **Step 2: Import Repository**
1. Select your GitHub repository: `Vanguard-Trading`
2. Vercel auto-detects Next.js
3. Set **Root Directory** to `frontend-next`

### **Step 3: Configure Environment Variables**

In Vercel project settings → Environment Variables, add:

```env
# Backend API URL (from Railway)
NEXT_PUBLIC_API_BASE_URL=https://your-backend-url.railway.app

# Site URL (Vercel will provide this)
NEXT_PUBLIC_SITE_URL=https://your-app.vercel.app
```

### **Step 4: Deploy**
1. Click "Deploy"
2. Vercel builds and deploys (takes ~2 minutes)
3. You get a URL like: `https://vanguardia-financial.vercel.app`

### **Step 5: Update Backend CORS**

Go back to Railway dashboard and update `CORS_ORIGINS`:

```env
CORS_ORIGINS=https://your-app.vercel.app,https://vanguardiafinancial.com
```

### **Step 6: Add Custom Domain (Optional)**

In Vercel:
1. Go to Settings → Domains
2. Add `vanguardiafinancial.com`
3. Update DNS records (Vercel provides instructions)
4. SSL certificate auto-generated

## **Alternative Option: Render (Free Tier)**

If you want a completely free deployment:

### **Backend on Render (Free)**

1. Go to https://render.com
2. New → Web Service
3. Connect GitHub repo
4. Settings:
   - **Root Directory**: `backend`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - **Environment**: `Python 3.11`

5. Add PostgreSQL database (free tier)
6. Add environment variables (same as Railway)

**⚠️ Note**: Free tier sleeps after 15 minutes of inactivity (slow first request)

### **Frontend on Vercel (Free)**
Same steps as above

## **Post-Deployment Checklist**

### **1. Update CORS Settings**
Make sure backend `CORS_ORIGINS` includes your frontend domain.

### **2. Run Database Migrations**

**Railway/Render**:
```bash
# In Railway dashboard, open shell and run:
alembic upgrade head
```

**Or use Railway CLI**:
```bash
railway run alembic upgrade head
```

### **3. Test All Features**
- ✅ User registration
- ✅ Login/logout
- ✅ Market data loading
- ✅ Trading functionality
- ✅ Portfolio tracking

### **4. Monitor Performance**
- Railway: Built-in metrics dashboard
- Vercel: Analytics dashboard

### **5. Set Up Monitoring (Optional)**
- **Sentry** for error tracking
- **LogRocket** for session replay
- **Uptime Robot** for uptime monitoring
